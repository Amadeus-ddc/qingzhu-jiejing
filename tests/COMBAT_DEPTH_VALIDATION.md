# 玄骨与主动战斗改版 · 2026-09-12

## 行为与操作

- Z 切换剑势。护卫剑保留近身伤害，六口以上可在实体飞剑位置拦弹，每次消耗 3 灵力，有 0.45 秒间隔。强攻提高追击速度和伤害，取消护卫伤害及拦弹，在近敌存在时持续耗灵；灵力耗尽自动归守。所有模式和镇阵共用现有剑池。
- C 祭出主祭法宝，V 或行囊切换。十二种已有法门各自获得主动招式，涵盖剑气贯穿、追魂标记、引爆灼烧、镇敌、蚀甲、血网、冻结、三具傀儡、火雨、清弹、消煞与突进。只可主祭已学法门，换器不重置共享冷却。主动技能与角色法术共用灵力。
- 冰火衔接触发寒热爆裂，同一目标有反应间隔。主动攻击、部分角色法术、击碎敌方法宝削减首领定力。压制槽满后打断蓄力、取消尚未落下的攻击，获得 2.6 秒破绽；有 7 秒破招恢复间隔。
- 墨蛟保留突进与毒息，加入有内圈安全区的扫尾，半血后突进接扫尾。婴鲤兽加入连续潮线、带缺口的珠轮与可击碎的海珠护体。
- 玄骨分 68%、32% 生命阈值的三阶段。第一阶段使用骨剑、骨镜、骨链和玄阴幡；第二阶段加入幻身换形、冰焰、环煞；第三阶段加入骨链与环煞组合。行动选择考虑距离与近期使用次数，开始蓄力后不再跟随玩家改瞄。换形落点提前显示并校验可站立地形。
- 敌方法宝有独立外观、生命、攻击预警与存续时间。击碎解除护体并压制定力，不产生经验、材料或击杀奖励。首领死亡后清除其法宝与敌方残留攻击。
- 第 4、5 版存档保留已赚取的装备与材料并补充新控制状态。第 6 版存档保留当前阶段、法宝、冷却与剑势。

## 验证范围

- `npm test`：55 项通过，覆盖旧战斗与地形回归、十二种祭器行为、共享冷却、剑势耗灵与实体拦弹、环形/直线伤害、安全换形、各阶段招式、法宝破坏、破招取消与存档迁移。
- `npm run test:balance`：三名角色各两种选牌策略，六组普通操作模拟均通过三境，峰值怪物 174。模拟不是浏览器整局游玩，也不能代替玩家对难度和趣味的判断。
- `node tests/pixel-duel-sim.mjs`：相同预设七十二剑装备，对比原地、连续绕圈及主动应对。数据位于开发目录 `artifacts/qa/combat-depth/duel-simulation.json`。绕圈仍可能获胜，未把所有强构筑改成必须按固定连招才能通关。
- `node tests/pixel-combat-browser.mjs`：真实页面、预设后期装备，使用桌面键盘及横屏触控验证主祭选择、剑势切换、冷却保存和玄骨战。桌面与横屏触控均完成三个阶段的玄骨战，主祭选择、剑势切换与共享冷却通过，页面错误为 0；P95 帧间隔分别约 16.7 / 16.8 ms。结果与阶段截图保存在 `artifacts/qa/combat-depth/browser-combat.json` 及同目录；这不是从开局起玩的完整浏览器通关。

可复现的预设装备在 `tests/pixel-late-build.json`；只在测试中使用，不随静态游戏构建发布。过程截图、模拟结果与线上验收证据仅留在开发目录。
