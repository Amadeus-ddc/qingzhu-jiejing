# 玩家反馈修订 · 2026-09-11

## 本次行为

- 初始蛛潮每 2.2 秒一只，第一轮截路推迟到第 35 秒，改为每 1.5 秒两只。初始怪物更脆、更慢。
- 普通敌人的生命倍率在各自波次基础上随境内进度与境次增长。收割、压迫和回息阶段仍有区别；不读取玩家伤害或击杀效率动态加难。
- 普通步行正对树石时尝试沿空闲切向小步绕行。每个小步检查地形，闪避与穿行技能没有获得穿墙能力。
- 地图目标显示当前行动提示，材料不足时不再优先指向炼器台，守护灵圃时优先显示守护目标。手机横屏保留目标与倒计时。
- 每境第 60 秒后可从地图下方选择提前挑战。确认后跳到首领出现前 5 秒；取消保持原节奏；不补发跳过敌潮的经验、材料或灵石。
- 击败首领立即开放界门，玩家可主动离境，也可继续探索。原有定时自动离境兜底保留。
- 新增首领招式和法门替换属于玩家列明的后续目标，本次不扩展这两个系统。

## 验证与边界

`npm test` 通过 44 项测试，覆盖正常战斗、旧存档、三境地形、远处寻路、怪物波次、首领招式，以及本次提前挑战、界门、目标选择、绕障回归。

`npm run test:balance` 六组确定性模拟均完成三境。三名角色分别使用飞剑和元素选择策略；峰值同时在场怪物为 198。模拟以普通游戏操作推进，不等同浏览器整局实玩，也不能代替玩家对难度的反馈。

`node tests/pixel-feedback-browser.mjs` 桌面与触屏两组通过，无页面运行错误。用实际键盘操作从新局推进到 60 秒，检查取消/确认提前挑战、5 秒后首领出现，再在 844×390 触屏环境用同一份正常获得的存档复查。此流程只验证开局与新增交互，不声称浏览器整局通关。

本地证据在 `artifacts/qa/player-feedback/`，包含过程截图、正常取得的存档与结果；六组模拟在 `artifacts/qa/pixel-balance.json`。过程证据不随公开静态站打包。
